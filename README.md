## SunCart

SunCart is a modern summer-focused e-commerce web application built with Next.js. Users can browse products, view product details, register/login securely, and manage their profile through a clean responsive interface.

---

# Live URL

🔗 https://sun-cart-dusky.vercel.app/

---

# Project Purpose

The purpose of SunCart is to provide a simple and responsive online shopping experience focused on summer-related products such as skincare, handheld fans, fashion accessories, and sun protection items.

---

# Key Features

1. Authentication System (Login/Register/Logout)
2. Protected Product Details Route
3. User Profile Page
4. Update Profile Functionality
5. Fully Responsive Design
6. Dynamic Product Cards
7. Product Details Page
8. Summer Care Tips Section
9. Top Brands Section
10. Optimized Image Loading with Next.js Image
11. Modern UI with Tailwind CSS
